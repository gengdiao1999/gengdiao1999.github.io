---

## 1. 设计目标

当前第 3 章的季节性强度（3.3.2 节）和趋势强度（3.4.3 节）示例只给出了单一合成序列及一个指标值：

- 读者看到 $F_s = 0.923$，但不知道“0.2”“0.5”“0.9”分别对应什么样的季节波形；
- 读者看到 $F_t = 0.831$，但无法判断“趋势弱 / 中 / 强”在时间序列上的直观差异。

本设计通过**强度阶梯图**（weak / medium / strong）在同一图中并列展示不同强度等级下的序列走势与对应指标值，帮助读者建立“数值—形态”直觉。

## 3. 设计方案

### 3.1 总体布局：强度阶梯图

每个特征生成**一张图**，纵向排列 3 个子图，分别对应：

1. **弱**（low strength，$F \approx 0.1\sim0.3$）
2. **中**（medium strength，$F \approx 0.5\sim0.7$）
3. **强**（high strength，$F \approx 0.9$ 以上）

每个子图只绘制**原始序列**，并在子图标题或右上角标注计算出的强度值。不展示 STL 分解细节，避免信息过载；原图 3-4 / 3-5 的分解逻辑保留在正文中。

### 3.2 季节性强度示例（图 3-4）

**合成模型**：

```
x_t = 0.02 * t + amp * season(t) + noise_t
```

- 趋势项固定为 $0.02 t$，避免趋势过强干扰 $F_s$；
- `season(t)` 为周期 24 的正弦/余弦组合；
- 通过改变 `amp`（季节振幅）和 `noise_t` 标准差，得到三个强度等级；
- 使用 `statsmodels.tsa.seasonal.STL` 分解后计算 $F_s = 1 - \frac{\text{Var}(R_t)}{\text{Var}(S_t + R_t)}$。

**目标强度区间**：

| 等级 | 目标 $F_s$ | 实现思路 |
|------|-----------|----------|
| 弱   | 0.15~0.25 | 季节振幅小，噪声相对大 |
| 中   | 0.55~0.70 | 季节振幅与噪声适中 |
| 强   | 0.90~0.98 | 季节振幅大，噪声小 |

**视觉元素**：

- 每个子图标题形如“弱季节性  $F_s = 0.21$”；
- x 轴：时间步；y 轴：取值；
- 三张图使用统一的 y 轴范围，便于横向对比；
- 用细竖线或阴影标出一个完整周期（24 步），帮助读者识别重复模式。

### 3.3 趋势强度示例（图 3-5）

**合成模型**：

```
x_t = slope_factor * trend(t) + low_freq(t) + noise_t
```

- `trend(t)` 为分段线性趋势（前半段上升、后半段下降），避免与线性 $R^2$ 混淆；
- `low_freq(t)` 为低频波动，作为“非趋势、非噪声”的中间成分；
- 通过改变 `slope_factor` 放大/缩小趋势项，得到三个强度等级；
- 使用 `STL` 分解后计算 $F_t = 1 - \frac{\text{Var}(R_t)}{\text{Var}(T_t + R_t)}$。

**目标强度区间**：

| 等级 | 目标 $F_t$ | 实现思路 |
|------|-----------|----------|
| 弱   | 0.15~0.25 | 趋势斜率小，噪声与低频波动占主导 |
| 中   | 0.55~0.70 | 趋势项与噪声/低频成分相当 |
| 强   | 0.90~0.98 | 趋势斜率大，噪声相对小 |

**视觉元素**：

- 每个子图标题形如“弱趋势性  $F_t = 0.23$”；
- 在同一张子图上叠加 **STL 趋势项**（用不同颜色），让读者看到“趋势项”如何主导序列；
- x 轴：时间步；y 轴：取值；
- 三张图统一 y 轴范围，便于横向对比；
- 保留原始序列（primary 色）与 STL 趋势（accent 色）的图例。

### 3.4 图片风格

遵循 `CLAUDE.md` 第 4 节图片规范：

- 使用统一调色板（`primary`/`secondary`/`accent`/`danger`/`neutral`/`background`）；
- 输出 PNG，300 dpi，宽度不超过 1600 px；
- 中文字体优先使用 bundled `wqy-microhei.ttc`；
- 标题、坐标轴标签使用中文；
- 图例无边框、无背景色；
- 使用 `bbox_inches="tight"` 减少白边；
- 推荐 `figure.figsize = (10, 5.5)` 左右，保证 3 行子图既不拥挤也不空旷。
