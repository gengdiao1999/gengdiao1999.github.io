## 3. 各小节内容规格

### 3.1 统计特征

- **定义**：用少量标量刻画序列取值分布与局部窗口特性的特征。
- **3.1.1 基本统计量**：均值、中位数、众数、方差、标准差、极差、IQR，给出公式与 `numpy`/`pandas` 代码。
- **3.1.2 分布形态特征**：偏度、峰度，说明工程含义（右偏/左偏、厚尾/轻尾）。
- **3.1.3 能量与计数特征**：绝对能量、RMS、过零率。
- **3.1.4 滑动窗口统计特征**：滚动均值、标准差、极差、偏度、峰度及聚合方式。

复用现有脚本：`03-example-01-basic-stats.py`、`03-example-02-rolling-stats.py`。

### 3.2 平稳性特征

- **3.2.1 定义与解释**：平稳性指序列的统计特性（均值、方差、自相关结构）不随时间显著变化；区分严平稳与宽平稳；说明对 ARMA/ARIMA 等模型的重要性。
- **3.2.2 ADF 检验**：回归模型、原假设、特征提取（统计量、p-value、是否平稳）。
- **3.2.3 KPSS 检验**：与 ADF 假设互补，特征提取方式。
- **3.2.4 滚动统计量稳定性**：滚动均值/方差及其变异系数，用于局部平稳性刻画。

复用现有脚本：`03-example-03-stationarity-features.py`。

### 3.3 季节性特征

- **3.3.1 定义与解释**：季节性指序列在固定时间间隔（小时、天、周、年）上重复出现的模式；与周期性的区别。
- **3.3.2 季节性强度**：基于 STL 分解 $x_t = T_t + S_t + R_t$，$F_s = 1 - \frac{\text{Var}(R_t)}{\text{Var}(S_t + R_t)}$。
- **3.3.3 周期内统计量**：按周期位置分组，计算均值、标准差、偏度、峰度。
- **3.3.4 季节滞后自相关特征**：在滞后 $m, 2m, 3m$ 处的 ACF 值。

复用现有脚本：`03-example-04-seasonality-features.py`。

### 3.4 趋势性特征

- **3.4.1 定义与解释**：趋势性指序列在长期尺度上的持续上升、下降或稳定倾向；与季节性的区别。
- **3.4.2 线性趋势特征**：$x_t = \beta_0 + \beta_1 t + \varepsilon_t$，提取斜率、截距、$R^2$。
- **3.4.3 趋势强度**：基于 STL 分解，$F_t = 1 - \frac{\text{Var}(R_t)}{\text{Var}(T_t + R_t)}$。
- **3.4.4 Mann-Kendall 趋势检验**：Kendall's $S$、非参数趋势显著性。
- **3.4.5 局部趋势变化特征**：滚动窗口斜率及其符号变化次数。

复用现有脚本：`03-example-05-trend-features.py`。

### 3.5 周期性特征

- **3.5.1 定义与解释**：周期性指序列中重复出现的波动模式，周期长度可与日历无关；与季节性的区别。
- **3.5.2 ACF 峰值法**：自相关函数、置信区间、周期估计。
- **3.5.3 周期图峰值法**：FFT 幅度谱、主导频率、周期 $T = 1/f$。
- **3.5.4 滚动周期稳定性**：滚动窗口周期估计的标准差。

复用现有脚本：`03-example-06-periodicity-features.py`。

### 3.6 频域特征

- **3.6.1 傅里叶变换特征**：DFT、主导频率、主导幅值、低/高频能量比。
- **3.6.2 功率谱密度特征**：Welch 法、谱熵、谱质心、谱带宽。
- **3.6.3 频带能量特征**：低/中/高频带能量占比。

复用现有脚本：`03-example-07-frequency-features.py`。

### 本章小结

- 回顾 3.1–3.6 各特征的核心思想与典型用途。
- 指出特征组合、多尺度窗口、任务适配是后续工程关键。
- 提示下一章将深入时域分析方法。
