# 第 3 章习题

## 基础题

1. 给定序列 $\mathbf{x} = [3, 1, 4, 1, 5, 9, 2, 6]$，手动计算：
   - 均值、标准差、中位数
   - 极差、四分位距（IQR）
   - 偏度与峰度（可用 `scipy.stats` 验证）

2. 为什么对非平稳序列更适合使用滑动窗口统计特征，而不是全局统计特征？

## 编程题

3. 使用 `pandas`，对 `03-example-01-rolling-stats.py` 生成的序列计算窗口大小分别为 10、20、50 的滚动标准差，并绘制在同一张图上。观察窗口大小对曲线平滑程度的影响。

4. 实现一个基于滚动均值 ±3 倍滚动标准差的异常点检测函数，并在示例序列上标出检测到的异常点。

## 进阶题

5. **平稳性判定**。生成以下两个序列（长度 $N=500$）：
   - $x_t^{(1)} = \varepsilon_t$，其中 $\varepsilon_t \sim \mathcal{N}(0, 1)$；
   - $x_t^{(2)} = \sum_{i=1}^{t}\varepsilon_i$，即随机游走。

   分别对两个序列计算 ADF 检验与 KPSS 检验的统计量和 p-value，并根据原假设与 p-value 判断它们是否平稳。当 ADF 与 KPSS 结论冲突时，应如何进一步分析？

6. **季节性强度**。使用 `statsmodels.tsa.seasonal.STL` 对如下合成序列进行分解：

   $$
   x_t = 5\sin\left(\frac{2\pi t}{24}\right) + \varepsilon_t, \quad t=0,1,\dots,479,
   $$

   其中周期 $m=24$，$\varepsilon_t \sim \mathcal{N}(0, 1)$。计算季节性强度 $F_s = 1 - \frac{\text{Var}(R_t)}{\text{Var}(S_t + R_t)}$，并解释其数值含义。

7. **线性趋势拟合**。生成序列 $x_t = 0.05t + \varepsilon_t$（$t=0,1,\dots,199$，$\varepsilon_t \sim \mathcal{N}(0, 1)$）。使用最小二乘法拟合直线 $x_t = \beta_0 + \beta_1 t$，报告斜率 $\beta_1$、截距 $\beta_0$ 与决定系数 $R^2$，并解释斜率 $\beta_1$ 的实际意义。

8. **周期性估计**。生成合成序列：

   $$
   x_t = 2\sin\left(\frac{2\pi t}{12}\right) + \varepsilon_t, \quad t=0,1,\dots,359,
   $$

   分别用 ACF 峰值法和周期图峰值法估计其周期，并比较两种方法的估计结果。若加入趋势项 $0.02t$ 后再估计，结果会发生什么变化？

9. **频域能量比**。生成由低频与高频分量叠加的序列：

   $$
   x_t = 2\sin\left(\frac{2\pi t}{50}\right) + 0.5\sin\left(\frac{2\pi t}{5}\right) + \varepsilon_t, \quad t=0,1,\dots,999,
   $$

   采样频率 $f_s = 1$。计算 FFT 后低频段（$0 \le f < 0.05$）与高频段（$0.15 < f \le 0.5$）的能量比 $R_{\text{L/H}}$。解释该比值大小反映了信号的什么物理特征。

## 思考题

10. 在时序分类任务中，如果直接使用全局统计量作为特征，可能会丢失哪些信息？应如何补充？

11. 偏度和峰度对异常检测有什么价值？什么类型的异常会显著改变这两个统计量？
