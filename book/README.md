# 前言

时间序列数据广泛存在于工业监控、金融交易、气象预测、医疗健康等领域。如何从 noisy、高维、非平稳的时序数据中提取有效信息，并进一步完成分类、异常检测、预测与因果分析，是数据科学与人工智能领域的核心问题之一。

本书的目标是提供一条从基础到进阶的**系统学习路线**：

1. **特征提取**：从统计量、形状子、频域特征到深度学习表征，建立对时序数据的多视角描述。
2. **时域分析**：理解趋势、季节性、自相关、平稳性等关键概念。
3. **频域分析**：掌握傅里叶变换、小波分析、谱估计等工具。
4. **时序分类**：从基于距离、特征、深度学习到集成方法。
5. **时序异常检测**：从统计方法、机器学习到深度学习和根因分析。
6. **时序预测**：单指标与多指标预测方法。
7. **时序因果分析**：Granger 因果、因果发现与反事实推理。

## 阅读路线

- **快速入门**：基础篇 → 特征提取 → 时序分类/异常检测
- **系统深入**：按篇顺序阅读，配合每章代码实践
- **论文/专利延伸阅读**：附录 A、B 提供大量 AIOps 与时序分析相关文献

## 本书特色

- **理论与实践并重**：每章均包含数学原理与可运行 Python 代码。
- **模块化组织**：每章独立成文件夹，预留图片、代码、数据目录，便于扩展。
- **图文并茂**：图片优先由 Python 脚本生成，保证可复现。
- **资料附录**：论文、专利独立成章，作为正文的有力补充。
